# Astro engineering

- Prefer Astro components and static/server rendering; add framework islands only where interaction requires them.
- Minimize shipped JavaScript and choose hydration directives deliberately.
- Use content collections and schemas for structured content.
- Keep layouts, routes, assets, and server endpoints explicit.
- Choose static, server, or hybrid rendering from product requirements and deployment constraints.
- Optimize images/assets and preserve semantic accessible HTML.
- Load React or another framework skill only for actual integrated components.
